## What is CubePath?

[CubePath](https://cubepath.com) is a cloud hosting provider offering Cloud VPS and Bare Metal servers.

Our infrastructure supports developers, freelancers, and businesses running:

- Web applications and SaaS projects
- Docker containers and self-hosted services
- AI agents and automation workflows
- APIs and databases
- Development and production environments
