# Deploy Coolify on a CubePath VPS

Learn how to install and configure Coolify on an Ubuntu 24.04 VPS hosted by CubePath.

Coolify is an open-source, self-hosted platform that lets you deploy applications, databases, and services using Docker, with support for Git-based deployments and HTTPS.

## Requirements

Before getting started, you will need:

- A VPS running Ubuntu 24.04 LTS
- At least 2 vCPUs, 2 GB RAM, and 30 GB of available disk space
- SSH access with root or sudo privileges
- A domain name pointing to your server
- Available ports 80 and 443

For multiple application builds, 4 GB RAM or more is recommended.

## What you'll learn

This tutorial covers:

1. Configuring DNS records
2. Setting up the firewall
3. Installing Coolify
4. Creating an administrator account
5. Enabling HTTPS with your own domain
6. Deploying an application from Git
7. Setting up PostgreSQL and backups
8. Updating and troubleshooting Coolify
